# Documentacao do Tavolo

Esta pasta organiza a documentacao por rotas e areas do sistema.

## Comece aqui

- INDEX.md (rotas e navegacao)
- CHANGELOG.md (historico de mudancas)
- TESTING.md (execucao de testes)
- DEPLOYMENT.md (deploy e validacao)

## Convencoes

- Documentos devem indicar rotas relacionadas no topo.
- Exemplos devem usar dados reais do sistema (ex.: venda_id nas APIs fiscais).
- Padrao de formato pt-BR: data, hora e moeda.
- Imagens ficam em docs/images/.
