# Roadmap v1.0.1 - Multi-Connections & TUI Refinement

## Detailed Functional View
Cambalhota version 1.0.1 introduces connection management directly through the user interface (TUI), eliminating the need for environment variables. The main focus is to enable registering multiple data sources and to allow cross data migration (backup from one source and restore into another target) smoothly.

### Business Requirements Met:
1. **Configuration via TUI:** Elimination of `.env` for credentials. All configuration becomes visual.
2. **Secure Storage:** Credentials will be persisted in a local SQLite file (`~/.cambalhota/connections.db`), protected with AES-256 encryption (the product standard).
3. **Multiple Databases:** Support for managing N connections in parallel.
4. **Cross Backup and Restore (Cross-Database):** Ability to extract from one database (Source) and restore into another (Target).
5. **Visual Identity:** Inclusion of a "Retrowave" Logo/Name in ASCII Art in the top-left corner of the TUI.

## User Journey (TUI)
1. **Initial Access & Logo:** When opening Cambalhota, the user sees the "Retrowave"-style ASCII Art logo in the top-left corner.
2. **"Manage Connections" Tab:**
   - The user navigates to the new connections tab.
   - Presses a shortcut (e.g., `Insert` or `[New Connection]`) to open the form.
   - Fills in the details: Name, Database Type, Host, Port, User, Password and Schema.
   - The password is masked. On save, the system encrypts it with AES before writing it to SQLite.
3. **"Backup & Extraction" Tab:**
   - The user selects the "Source" connection through a selection panel.
   - Runs the extraction. The system uses the stored credentials to connect and generate the dump.
4. **"Restore & Import" Tab:**
   - The user sees the dumps available locally.
   - Selects the dump file.
   - Selects the "Target" connection from the saved connections.
   - Confirms the operation, performing the cross restore.

## Acceptance Criteria
- [ ] The application must not require/read environment variables for database credentials.
- [ ] The "Connections" tab must allow full CRUD of databases.
- [ ] The local SQLite database must store the password encrypted (AES).
- [ ] The system must allow running Dump and Restore with different sources and targets.
- [ ] The Retrowave Logo (ASCII) must be displayed globally in the top-left header of the TUI.
