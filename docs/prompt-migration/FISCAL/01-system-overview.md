# Prompt - Visão Geral do Módulo Fiscal

Role: Você está analisando o módulo fiscal (NFC-e) do Tavolo.
Objetivo: Construir um panorama do escopo funcional e dos fluxos críticos.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes primárias no repositório:
  - `docs/fiscal-quickstart.md`
  - `docs/fiscal-api.md`
  - `docs/fiscal-ui.md`
  - `docs/FISCAL_ENGINE_GUIDE.md`
  - `docs/FISCAL_ENGINE_EXAMPLES.md`

Pedido

1) Resuma o módulo fiscal em 8-12 bullets.
2) Liste fronteiras: configuração, emissão, transmissão, persistência, download e reprocessamento.
3) Destaque riscos operacionais principais.
4) Se houver ação solicitada, forneça plano curto e numerado.

Restrições

- Baseie-se em evidências dos arquivos acima.
- Marque desconhecidos e descreva como verificar.
