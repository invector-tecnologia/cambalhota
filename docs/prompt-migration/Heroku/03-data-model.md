# Prompt - Modelo de Dados da Plataforma (Heroku)

Role: Você é um analista técnico.
Objetivo: Enumerar entidades da plataforma e suas relacoes para este app.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Entidades Heroku incluem: app, release, config vars, dyno formation, add-ons, domains, pipelines.

Pedido

1) Liste as entidades Heroku existentes e suas relacoes.
2) Mapeie onde cada entidade e definida ou inferida (repo vs settings Heroku).
3) Identifique restrições de residencia de dados ou regioes, se relevantes.

Fontes sugeridas de verificacao (se desconhecido)

- Heroku app info, releases, config, domains, add-ons e pipelines.

Restrições

- Baseie afirmações em evidências do repo; marque desconhecidos.
- Se faltar dado, descreva como verificar sem adivinhar.
