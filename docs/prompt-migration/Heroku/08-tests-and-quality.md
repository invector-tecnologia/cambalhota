# Prompt - Testes, CI e Quality Gates (Heroku)

Role: Você é um engenheiro de releases.
Objetivo: Descrever como testes, ambientes de review e segurança de release são tratados.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Pipelines e review apps suportam deploys em estagios.
- Release phase pode executar migracoes ou checks.

Pedido

1) Identifique entrypoints de teste e scripts de CI usados no deploy Heroku.
2) Note uso de pipeline, review app ou staging.
3) Identifique tarefas de release phase e impacto de falha.
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Baseie afirmações em evidências do repo ou docs explicitas.
- Marque desconhecidos e liste passos de verificacao.
