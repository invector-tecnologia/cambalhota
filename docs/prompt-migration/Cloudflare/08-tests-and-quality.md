# Prompt - Testes, Staging e Quality Gates (Cloudflare)

Role: Você é um engenheiro de releases.
Objetivo: Descrever testes, staging e mecanismos de rollout seguro.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Produtos Cloudflare oferecem rollbacks, rulesets e configuracoes em estagios.

Fontes primárias

- <https://developers.cloudflare.com/pages/>
- <https://developers.cloudflare.com/workers/>
- <https://developers.cloudflare.com/waf/>
- <https://developers.cloudflare.com/rules/>

Pedido

1) Identifique capacidades de rollout/rollback (Pages rollbacks, rules updates).
2) Note ambientes de teste ou preview para Workers/Pages.
3) Liste estrategias de mudanca segura (rules em estagio, rollout controlado), se documentadas.
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Cite docs oficiais.
- Marque desconhecidos e liste como verificar.
