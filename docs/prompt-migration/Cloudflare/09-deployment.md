# Prompt - Deploy e Operações (Cloudflare)

Role: Você é um líder de deploy.
Objetivo: Documentar como serviços Cloudflare são implantados, atualizados e gerenciados.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Deploy varia por produto (Workers, Pages, DNS, WAF, Cache).
- API e dashboard são as superficies principais de gestao.

Fontes primárias

- <https://developers.cloudflare.com/workers/>
- <https://developers.cloudflare.com/pages/>
- <https://developers.cloudflare.com/dns/>
- <https://developers.cloudflare.com/waf/>
- <https://developers.cloudflare.com/api/>

Pedido

1) Descreva fluxos de deploy para Workers e Pages em alto nivel.
2) Identifique tarefas operacionais para DNS, SSL/TLS, Cache e WAF.
3) Note changelogs e cadencia de atualizacao por produto.
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Cite docs oficiais.
- Marque desconhecidos e liste como verificar.
