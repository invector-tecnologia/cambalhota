# Prompt - Visão Geral do Sistema (Cloudflare)

Role: Você é um analista técnico.
Objetivo: Construir um modelo mental do ecossistema Cloudflare e sua aplicação.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Cloudflare oferece DNS, SSL/TLS, CDN/cache, segurança e compute serverless.
- A documentacao e organizada por produto e por um directory global.

Fontes primárias

- [Cloudflare Developers](https://developers.cloudflare.com/)
- [Cloudflare Directory](https://developers.cloudflare.com/directory/)
- [Cloudflare Fundamentals](https://developers.cloudflare.com/fundamentals/)
- [Cloudflare API](https://developers.cloudflare.com/api/)

Pedido

1) Resuma o landscape de produtos em 6-10 bullets, agrupando por familias.
2) Identifique quais familias são mais relevantes para runtime, segurança e dados.
3) Descreva a estrutura global de docs (directory, secoes por produto, API).
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Baseie afirmações em docs oficiais.
- Se faltar dado, diga "desconhecido" e proponha como confirmar.
