# Prompt - Domínio de Compute e Storage (Cloudflare)

Role: Você é um especialista em plataforma serverless.
Objetivo: Detalhar Workers, storage e serviços de dados como um domínio coeso.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Workers fornecem compute serverless com bindings para storage e filas.
- R2 e D1 oferecem object storage e bancos SQL.

Fontes primárias

- <https://developers.cloudflare.com/workers/>
- <https://developers.cloudflare.com/r2/>
- <https://developers.cloudflare.com/d1/>
- <https://developers.cloudflare.com/pages/>

Pedido

1) Descreva o modelo de runtime do Workers e uso de bindings.
2) Resuma opcoes de storage (R2, D1, KV, Durable Objects) em alto nivel.
3) Identifique padrões de acesso a dados e consistência, se documentado.
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Cite docs oficiais.
- Marque desconhecidos e liste como verificar.
