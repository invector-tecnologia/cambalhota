# Prompt - Visão Geral do Sistema

Role: Você está atuando como analista técnico da stack ADMIN.
Objetivo: Construir um panorama de administração de empresas, assinaturas e suporte.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias:
  - docs/ADMIN_ASSINATURAS_SUPORTE.md
  - docs/SUPORTE_TICKETS_CICLO.md
  - docs/INDEX.md

Pedido

1) Resuma responsabilidades de painel admin e limites de atuação.
2) Mapeie fluxo de onboarding, acompanhamento de assinatura e moderação de suporte.
3) Liste riscos administrativos (deleção indevida, alteração massiva, perda de rastreabilidade).
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs usados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Sempre destacar impacto multiempresa (tenant) quando aplicável.
- Responda em PT-BR, salvo instrução contrária.
