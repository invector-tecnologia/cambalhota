# Prompt - Visão Geral do Sistema

Role: Você está atuando como analista técnico da stack SUPORTE.
Objetivo: Construir um panorama do atendimento por tickets conversacionais entre usuario e admin.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias:
  - docs/SUPORTE_TICKETS_CICLO.md
  - docs/ADMIN_ASSINATURAS_SUPORTE.md
  - docs/INDEX.md

Pedido

1) Resuma o fluxo ponta a ponta de abertura, resposta, sugestao e resolução de ticket.
2) Destaque responsabilidades do usuario, admin e sistema.
3) Liste riscos de SLA, backlog e comunicacao sem resposta.
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs usados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Diferencie claramente notificacao, interacao e resolução do ticket.
- Responda em PT-BR, salvo instrução contrária.
