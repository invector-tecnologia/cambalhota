# Prompt - Visão Geral do Sistema

Role: Você está atuando como analista técnico da stack ESTOQUE.
Objetivo: Construir um panorama de cardápio, insumos, movimentações e controle de disponibilidade.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias: docs/INDEX.md, docs/ESTOQUE.md e docs/README.md.

Pedido

1) Resuma o escopo de cadastro de produtos/insumos e o impacto no cardápio.
2) Aponte integrações com compras/NFes e baixa por venda.
3) Liste riscos de acurácia de estoque e controles de reconciliação.
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs utilizados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Diferencie estoque de produto final versus estoque de insumo quando aplicável.
- Responda em PT-BR, salvo instrução contrária.
