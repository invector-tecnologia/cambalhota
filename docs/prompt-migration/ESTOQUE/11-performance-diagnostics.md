# Prompt - Diagnóstico de Performance

Role: Você está atuando como analista técnico da stack ESTOQUE.
Objetivo: Definir processo de RCA para divergencia de saldo e lentidao em consultas de estoque.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias:
  - docs/LOGGING.md
  - incidentes e rotinas de reconciliação
  - queries criticas de estoque

Pedido

1) Defina checklist de diagnóstico para saldo incorreto e indisponibilidade indevida.
2) Liste sinais para diferenciar erro de cadastro, processamento e consulta.
3) Estruture mitigacao imediata e correcao estrutural.
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs usados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Em RCA, sempre registrar impacto no cardápio e na operação de vendas.
- Responda em PT-BR, salvo instrução contrária.
