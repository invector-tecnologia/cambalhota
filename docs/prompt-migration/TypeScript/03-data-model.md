# Prompt - Modelo de Tipos e Dados

Role: Você está avaliando como o sistema de tipos modela dados.
Objetivo: Resumir tipos basicos, objetos, generics e padrões de modelagem.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Tipos primitivos, unioes e inferencia.
- Objetos: propriedades opcionais/readonly, index signatures, excess property checks.
- Estruturas genericas: Array, ReadonlyArray, tuplas, generics em funcoes e classes.
- Sistema estrutural (shape-based).

Fontes

- <https://www.typescriptlang.org/docs/handbook/2/basic-types.html>
- <https://www.typescriptlang.org/docs/handbook/2/everyday-types.html>
- <https://www.typescriptlang.org/docs/handbook/2/objects.html>
- <https://www.typescriptlang.org/docs/handbook/2/generics.html>
- <https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html>

Entregável

- Lista de construtos essenciais (interfaces, type alias, unioes, generics).
- Regras chave de objetos (opcionais, readonly, index signatures, excess checks).
- Quando preferir interface vs type alias.
- Padrões para colecoes e tuplas (Array, ReadonlyArray, tuplas com rest).
- Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Baseie tudo nas fontes acima.
- Marque desconhecidos claramente.
