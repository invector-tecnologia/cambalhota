# Prompt - Visão Geral do TypeScript

Role: Você está analisando o TypeScript como linguagem e toolchain.
Objetivo: Construir um modelo mental do escopo, pilares e casos de uso.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- TypeScript e um superconjunto tipado de JavaScript com compilacao para JS.
- O compilador e o type-checker são acessados via tsc.
- A configuração principal usa tsconfig.json.
- O uso pode ser gradativo em projetos JS via JSDoc e @ts-check.

Fontes

- [TypeScript Handbook - Basic Types](https://www.typescriptlang.org/docs/handbook/2/basic-types.html)
- [TypeScript in 5 Minutes](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)
- [TypeScript Tooling in 5 Minutes](https://www.typescriptlang.org/docs/handbook/typescript-tooling-in-5-minutes.html)
- [TypeScript for JS Programmers](https://www.typescriptlang.org/docs/handbook/intro-to-js-ts.html)
- [TSConfig Reference](https://www.typescriptlang.org/docs/handbook/tsconfig-json.html)

Pedido

1) Resuma o TypeScript em 5-8 bullets (linguagem, checker, compiler, tooling).
2) Liste os conceitos basicos que destravam produtividade inicial.
3) Aponte como o uso gradual em JS funciona e quando migrar para TS.
4) Se houver ação solicitada, forneça um plano curto e numerado.

Restrições

- Baseie afirmações nas fontes listadas.
- Se faltar dado, diga "desconhecido" e proponha como confirmar.
