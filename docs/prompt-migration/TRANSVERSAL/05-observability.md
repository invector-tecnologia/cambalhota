# Prompt - Observabilidade

Role: Você está atuando como analista técnico da stack TRANSVERSAL.
Objetivo: Definir base de observabilidade reutilizavel para todos os modulos.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias:
  - docs/LOGGING.md
  - handlers de erro globais
  - convenções de logs em controllers/services

Pedido

1) Liste sinais transversais minimos para detecao de incidente.
2) Defina campos padrão de log para correlacao entre modulos.
3) Aponte lacunas de observabilidade e propostas de padronizacao.
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs usados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Priorizar padrão de coleta e consulta, não apenas exemplos pontuais.
- Responda em PT-BR, salvo instrução contrária.
