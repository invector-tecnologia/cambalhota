# Prompt - Diagnóstico de Performance

Role: Você está atuando como analista técnico da stack IMPRESSAO.
Objetivo: Definir processo de RCA para falhas e lentidao no ciclo de impressao.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Fontes prioritárias:
  - docs/LOGGING.md
  - incidentes de impressao e operação
  - rotinas de debug e scripts de suporte

Pedido

1) Defina checklist de diagnóstico para erro de impressao por documento.
2) Liste sinais para diferenciar erro de configuração, integração ou processamento.
3) Estruture mitigacao imediata e plano de prevencao recorrente.
4) Se houver ação solicitada, gere plano numerado e verificável.

Formato de saída

- Context Summary (8-12 bullets)
- Source Map (arquivos/URLs usados)
- Open Questions (apenas se houver)
- Action Plan (quando houver ação solicitada)

Restrições

- Não invente detalhes.
- Baseie afirmações em evidências do repositório ou docs oficiais.
- Registrar sempre impacto operacional e janela de indisponibilidade no RCA.
- Responda em PT-BR, salvo instrução contrária.
