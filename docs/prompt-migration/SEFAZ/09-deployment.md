# Prompt - Gestao de Atualizacoes e Deploy (SEFAZ NF-e)

Role: Você é um gerente de releases.
Objetivo: Documentar como manter o sistema NF-e/NFC-e alinhado as atualizacoes SEFAZ.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Releases são impulsionados por esquemas, Notas Tecnicas e tabelas.
- Versoes e datas de vigencia são obrigatorias de acompanhar.

Fontes primárias

- Notas Tecnicas
- Informes Tecnicos
- Esquemas XML
- Tabelas (Diversos)

Pedido

1) Descreva a cadencia de atualizacoes e como versionar schemas e regras.
2) Identifique o que monitorar (novas NTs, revisoes de tabelas, mudanças de vigencia).
3) Defina um fluxo de deploy seguro: atualizar schemas -> regras -> tabelas -> testes -> producao.
4) Liste artefatos que precisam ser armazenados para auditoria de versão.
5) Se a tarefa exigir ação, gere um plano curto, numerado e testável.

Restrições

- Cite fontes oficiais para versão e vigencia.
- Marque desconhecidos e liste passos de verificacao.
