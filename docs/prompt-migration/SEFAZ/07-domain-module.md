# Prompt - Fluxo Fiscal Principal (SEFAZ NF-e)

Role: Você é um especialista no domínio fiscal.
Objetivo: Detalhar o ciclo de vida principal e o tratamento de contingencia.
Tom: Analítico para aquisição de contexto. Diretivo para passos de ação.

Contexto

- Ciclo típico: emitir -> autorizar -> armazenar -> distribuir -> registrar eventos.
- Contingencia pode incluir SVC ou procedimentos offline conforme manual.

Fontes primárias

- Manuais: <https://www.nfe.fazenda.gov.br/portal/listaConteudo.aspx?tipoConteudo=ndIjl+iEFdE=>
- Notas Tecnicas: <https://www.nfe.fazenda.gov.br/portal/listaConteudo.aspx?tipoConteudo=04BIflQt1aY=>

Pedido

1) Mapeie o ciclo completo de emissão para NF-e e NFC-e, com pre-condicoes e pos-condicoes.
2) Descreva modos de contingencia, quando ativar e como sincronizar depois.
3) Identifique eventos críticos e seus efeitos no documento fiscal.
4) Liste pontos de validação obrigatorios antes de transmitir.
5) Se a tarefa exigir ação, gere um plano curto, numerado e testável.

Restrições

- Cite manuais e anexos.
- Marque desconhecidos e liste passos de verificacao.
