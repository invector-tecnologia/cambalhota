# Iniciando um projeto com AiDD
## Estapa de descrição do projeto
[00. Descreva seu nome e seu nível de experiência em projetos de software].
[01. Descreva o propósito do projeto e seu público alvo].
[02. Descreva as funcionalidades principais do projeto (MLP), em forma de listagem ranqueada].
[03. Descreva o estilo de  layout do projeto].
[04. Descreva o que não pode conter no projeto].
[05. Descreva as tecnologias de frontend, backend, banco de dados e infraestrutura que seão utilizadas no projeto].
[06. Descreva o como seu projeto será documentado e como essa documentação deverá ser atualizada].
[07. Exija que seja criados: Mapa de Features, contendo todas as funcionalidades e seus comportamentos de tela].
[08. Exija que seja criados: Mapa de Evolução do Produto, tomando como base o Mapa de Features do projeto e  contendo um benchmark de concorrentes e liste os top 5 concorrentes].
[09. Exija que seja criado: Roadmap de Features, contendo todas as funcionalidades, seu valor de negócio e seus status de implementação].
[10. Exija que seja criado: Mapa de Arquitetura, da camada de classes e eventos do frontend e do backend do projeto e da camada de banco de dados do projeto]
[11. Peça que o projeto seja Instrumentado para utilizar todos os recursos que o antigravity pode proporcionar para um  AI Driven Development assertivo e de qualidade].

## Estapa de execução do projeto
[12. Planejamento: Utilize para isso ferramentas AiDD com o comando /plan com um bom modelo com uma quantidade ciclo de cognitivo alta]
[13. Execução: Utilize para isso ferramentas do AiDD /agent com um bom modelo com uma quantidade ciclo de cognitivo baixo e reforçando que o desenvolvimento siga restritamente o que foi planejado]
[14. Testes: Utilize para isso ferramentas do AiDD /test com um bom modelo com uma quantidade ciclo de cognitivo baixo e reforçando que os testes sigam restritamente o que foi planejado]
